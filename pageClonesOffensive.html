Technical Breakdown

Project Vision

Inspired by Star Wars roleplay servers on Garry's Mod, this project allows players to immerse themselves as clone troopers during the Clone Wars in a multiplayer PvE environment.

The primary engineering focus was mastering Unreal Engine 5 C++ architecture, client-server replication, server RPCs, and smooth actor synchronization.

Entity System

Designed a robust class hierarchy where all interactable world objects inherit from a base Entity class.

This unified structure allowed Items, Props, AI actors, and Players to share common interaction logic and network state, powering a fully replicated grid-based inventory with server-validated RPCs.

Replicated Stats Component

Built a lightweight Actor Component that handles health, armor, stamina, and status effects. It automatically binds to Unreal's native damage delegates.

Base statistics and scaling curves are data-driven via Primary Data Assets, making it easy to create new character classes and enemies without modifying code.
