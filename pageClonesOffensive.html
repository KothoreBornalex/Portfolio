    Pitch
    Inspired by the Star Wars Mod on Garry's Mod, this game lets you play as a clone during the clone wars. It's mostly PVE and multiplayer. One of the main goals for me doing this was to learn more about C++ in Unreal Engine and Network Replication.
    Entity System
    The system is based on class inheritance; every interactable object is an entity so that I can extend its behavior cleanly down the road.
    With this architecture, Items, Props, AI, and Players are entities, making it straightforward to build gameplay features and network replication (such as a replicated Inventory with RPCs).
    Stats System
    It is replicated and can be used on any actor as an Actor Component. It binds itself to the damage delegate, and base stats are configured using Primary Data Assets.
    This allows damage to be applied seamlessly to any actor utilizing Unreal Engine's native damage system.
