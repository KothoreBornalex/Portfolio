Key Features & Engineering

Project Overview

Detroit's Sacrifices is a high-octane FPS/TPS blending fluid gunplay with cyberspace hacking in a dystopian futuristic setting.

As a solo developer, I built the entire gameplay loop, character controller, weapons handling, enemy AI state machines, UI systems, and level design from scratch in Unity.

Dynamic Boss Encounters

Crafted multi-stage boss battles featuring distinct combat phases, dynamic telegraphing, destructible weak points, and reactive behavioral AI.

The encounter requires players to combine spatial awareness, precise shooting, and quick cyber-hacking to break shields and disable environmental hazards.

Cyberspace Hacking Mechanics

Developed an interactive real-time hacking system where players enter a stylized matrix world to bypass security firewalls, reprogram turrets, and extract data nodes.

The transition between real-world combat and cyberspace was optimized using custom post-processing shaders and time-dilation effects.
