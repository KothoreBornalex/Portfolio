    Pitch
    Wandering Traveller is a student project created to learn mobile game development in Unity. In this project we tackled hardware constraints on mobile platforms, developing custom performance workarounds to achieve high visual fidelity.
    Optimization Pipeline
    1. Zero-GC Object Pooling: eliminated memory allocations and GC spikes during intense wave spawns.

    2. Vertex Shader GPU Animations: baked character keyframes into texture maps stored in ScriptableObject Animation Banks.
    View Textured Animation Tool
    Performance Benchmark
    Before Optimization: ~16-25 FPS with only 30 AI units active on screen.

    After Custom GPU Pipeline: Solid 60 FPS lock with over 112 simultaneous active AI units.
    Gameplay Architecture
    Stats system, character controllers, AI behaviors, dynamic Day/Night cycle, core game loop, wave spawner system, and responsive mobile UI.
