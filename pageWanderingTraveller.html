    Wandering Traveller
    2023 - Mobile - Clicker - Unity - 3 Months - 2 Workers
    Optimization - Gameplay - C#
    Pitch
    Wandering Traveller is a student project created to learn mobile game development in Unity. In this project we tackled hardware constraints on mobile platforms, developing custom performance workarounds to achieve high visual fidelity.
    Optimization Approach
    First, an object pooling system to eliminate garbage collector spikes (achieving near 0 bytes GC allocations during gameplay).

    Second, a vertex-shader GPU animation pipeline: after baking character animations to textures, animations are stored into ScriptableObject Animation Banks.

    (Click to learn more about the Textured Animation Tool)
    Optimization Results
    Before the custom animation tool: ~16-25 FPS with 30 AI characters active on screen.

    After the custom animation pipeline: Framerate reached a locked 60 FPS with over 112 simultaneous AI characters rendered on screen.
    Gameplay
    Stats system, character controllers, AI behaviors, dynamic Day/Night cycle, core game loop, wave spawner system, and UI settings.
