Engine Architecture & Features

Project Overview

Bond is a student project created to learn C++ fundamentals and game engine architecture from the ground up, using only the SFML multimedia library for windowing and low-level rendering.

Working in a team of 3, we implemented memory management, collision physics, an entity system, and custom rendering passes completely from scratch.

Integrated Level Editor

Developed a standalone in-engine Level Editor allowing rapid authoring of complex maps with grid-based tile placement, entity spawner setup, and collision boundary painting.

Levels serialize directly to and from JSON files, enabling clean separation of data and runtime game code.

Core Entity Architecture

Engineered an extensible Entity system that acts as the backbone for all game objects. It manages deterministic tick updates, lifecycle events, memory cleanup, and AABB/circle collision layers.

2D Dynamic Line-of-Sight & Shadows

Implemented a 2D raycasting visibility algorithm that casts rays toward obstacle vertices, sorting intersection points to construct a dynamic visibility polygon.

Shadow geometry is dynamically generated and layered beneath buildings but above AI units, creating realistic stealth line-of-sight mechanics.
