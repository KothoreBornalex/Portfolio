    Pitch
    Bond is a student project created to learn C++ and the fundamentals of building a 2D game engine from scratch with SFML. It gave us a strong understanding of engine architecture, memory management, and C++ design patterns.
    Level Editor
    The custom Level Editor allowed rapid level design and testing. Level layouts, entity spawners, and obstacles were serialized and loaded dynamically from JSON files.
    Entities System
    An Entity management system serves as the engine's backbone: managing object lifecycles, memory cleanup, tick updates, and collision detection dispatch.
    Lights & Shadows
    A 2D raycasting system cast rays from light sources to occluder geometry corners. Polygons formed between ray impact points are rendered to generate real-time dynamic 2D shadows.
