    Pitch & Motivation
    Tex Anim is a Unity tool created to streamline production pipelines with vertex-shader animation systems based on textured animations.
    To make a mobile game (Click to check out Wandering Traveller), we needed a way to animate hundreds of characters simultaneously on low-end hardware. Encoding vertex animation into texture maps enabled pure GPU-driven mesh animation.
    View Wandering Traveller
    Baking & Storing Animations
    Using a custom Editor Window, the tool converts character keyframe animations into texture maps before storing them in a ScriptableObject Animation Bank.
    Texture Encoding Pipeline
    Each row of the texture represents an animation frame, each column corresponds to a mesh vertex, and each RGB pixel encodes a vertex's position offset at that frame.
    Custom GPU Animator
    A Custom Animator reads texture coordinates, manages smooth blending between states, and dispatches animation parameters to GPU vertex shaders.
    Node Graph Editor
    A node-based Graph Editor inspired by Unity's Animator Window was developed to allow state transitions, blend trees, and advanced parameter control.
