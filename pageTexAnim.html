Architecture & Pipeline

Motivation & Overview

While developing a mobile title requiring dozens of animated characters on screen simultaneously, traditional CPU skinned mesh renderers quickly overwhelmed the mobile GPU and CPU budget.

I developed Tex Anim to bake skeletal animations into high-precision texture maps, enabling instant vertex-shader evaluation on the GPU with zero CPU skinning overhead.

See this tool powering Wandering Traveller →

Animation Texture Baking

The tool bakes animation frames into an image matrix where each row represents an animation frame, each column corresponds to a vertex index, and each pixel's RGB channels store 3D vertex positions.

Baked data is packaged into modular ScriptableObject animation banks that can be shared across multiple character instances.

GPU Playback & Custom Shaders

A lightweight C# controller passes playback time and blend weights to a custom Vertex Shader. The shader samples vertex positions and interpolates between frames in parallel on the GPU.

This decoupled the animation loop from Unity's main thread and completely eliminated garbage collection allocations during crowd scenes.

Visual State Machine Editor

Developed a visual node graph editor inspired by Unity's native Animator Window.

The graph editor allows designers to visually configure animation transitions, crossfade times, trigger parameters, and looping rules while outputting directly to the GPU texture-driven pipeline.
